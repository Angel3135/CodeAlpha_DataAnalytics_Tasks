# Task 3: Data Visualization Dashboard - Student Performance

### CodeAlpha Data Analytics Internship

## 📌 Objective
To create a visualization dashboard that analyzes student performance based on study hours, attendance, gender and overall performance.

## 📊 Dataset
- Created synthetic student data with 22 students
- Columns: Gender, Study Hours, Attendance, Maths Marks, Average Marks, Performance

## 📈 Visualizations Created (4 Charts)

1.  **Study Hours vs Maths Marks (Scatter Plot):**
    Shows correlation between time spent studying and maths score.

2.  **Attendance vs Maths Marks (Scatter Plot):**
    Analyzes if regular attendance impacts marks.

3.  **Gender-wise Average (Bar Chart):**
    Compares average performance of Male vs Female students.

4.  **Performance Distribution (Pie Chart):**
    Shows distribution of students in Good / Average / Needs Improvement categories.

## 🔍 Key Insights
- Students studying more than 5 hours tend to score above 65.
- Attendance above 75% shows positive impact on performance.
- Gender-wise average is almost equal, no significant gap.
- 45% students are in Good category, 45% Average, 9% Needs Improvement.
