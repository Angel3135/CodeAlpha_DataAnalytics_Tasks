# Task 2 - Exploratory Data Analysis (EDA) - Student Performance

**Dataset:** 100 students (Maths, Science, English, Attendance, Study Hours)

**Analysis Done:**
1. Average Marks by Subject (Science highest ~70.51)
2. Average Attendance 82%, Study Hours 2.65 hrs
3. Correlation: Attendance vs Maths = ~0.01 (no relation), Study Hours vs Maths = 0.355 (positive)
4. Hypothesis Test: Study Hours significantly affect Maths Marks (p=0.00028, reject H0)
5. Performance Distribution: High-34, Medium-59, Low-7

**Files:**
- Raw_Data sheet: Original data
- Analysis sheet: Metrics, Charts, Key Findings
- Data_Dictionary sheet: Column meanings
- Visuals: Avg marks bar chart, Performance distribution

**Tools:** Excel, Python (Pandas, Scipy)
